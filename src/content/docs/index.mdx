## 核心原则

- **源码可用**：产品 Elastic License 2.0（ELv2），API 契约 MIT，文档 CC BY-SA 4.0。
- **协议对齐**：复用 Yggdrasil、Modrinth API、`.mrpack` 等事实标准。
- **现代化栈**：Go 后端 + TypeScript 前端，单二进制自托管友好。
- **按规模部署**：10 人私服到 10k 公共平台，组件可增可选。
