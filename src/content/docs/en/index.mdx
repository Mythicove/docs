## Principles

- **Open source first**: AGPL-3.0 products, MIT API contract, CC BY-SA 4.0 docs.
- **Protocol aligned**: reuse Yggdrasil, Modrinth API, `.mrpack` and other de-facto standards.
- **Modern stack**: Go backend + TypeScript frontend, self-host friendly.
- **Scale with tiers**: from a 10-player private server to a 10k public platform.
